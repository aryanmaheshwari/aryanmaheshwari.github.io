# aryan-portfolio

Personal portfolio — React 19, Vite, Tailwind CSS v4.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

**Editing content:** all copy (bio, stats, case studies, experience, projects, skills) lives in
[`src/data/content.js`](src/data/content.js). Components in `src/sections/` just render it.

**Theme:** design tokens (zinc neutrals + emerald accent, light/dark) are in [`src/index.css`](src/index.css).
